# 90-second demonstration

## 0:00 — Set the scene

“Cremorne has more than 700 businesses and 10,000 workers inside one square kilometre. Capacity exists, but it is fragmented across streets, buildings, time and tenancy.”

Open **Run the 90-second proof**.

## 0:12 — First pass

“It is a high-UV afternoon and Church Street is predicted to reach 82% load. With generic speed and crowding logic, Route B ranks first.”

Click **Run first-pass match**, then **Measure the outcome**.

## 0:30 — The reveal

“The aggregate result looks excellent: peak crowding falls 20% and walking time falls 7%. Then we ask a more useful question—who did we miss?”

Point to the low-UV and mobility outcomes.

“For the represented low-UV cohort, direct exposure rises 40%. For the mobility-constrained cohort, friction rises 15%. These are synthetic MVP outputs generated under the same controlled scenario.”

## 0:48 — Write Memory

Click **Write this boundary to Memory**.

“We store the context, outcome and boundary. We do not store the sentence ‘Route B works.’”

Click **Replay for Mia**.

## 1:02 — Next pass

“The same conditions return. Mia shares one functional requirement: low UV. The generic prediction still sees Route B as fast, but local Memory retrieves the previous exposed-crossing outcome before ranking. Route B sits outside her eligible set; Shadow Route C fits her exposure and arrival constraints.”

Point to the green route and retrieved-rule annotation.

## 1:22 — Generalise

Open **Test the same Memory on a room**.

“The same architecture discovers an authorised six-person hybrid room. Static metadata says two rooms qualify; local outcome evidence identifies the better fit. Same Memory, different capacity.”

## 1:35 — Close

“Cremorne Memory turns every measured decision into local operating knowledge. Use the capacity Cremorne already has. Learn from every outcome. Make the next decision better.”
