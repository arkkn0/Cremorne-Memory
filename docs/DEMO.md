# 90-second judge demo

## 0:00 — The worker problem

Open the landing page.

“Cremorne already has routes, covered passages and rooms. The problem is knowing which capacity is genuinely usable for a person at the moment they need it.”

Point to Mia’s sentence, then select **Plan a journey**.

## 0:15 — One clear worker task

Keep **Low UV** selected and choose **Find eligible routes**.

“It is a high-UV demo day. Mia shares a functional requirement, not a diagnosis. The product checks predicted exposure, arrival time and remaining route capacity before ranking.”

Point to **Canopy alternative — Best fit** and the filtered Direct route. Expand **Why this route?** once.

## 0:35 — Show where the rule came from

Select **CDH operator**, then **Replay from detection** if a rule is already active. Choose **Test redistribution**.

“CDH tests the same 300-worker scenario with the same UV and seed. Average crowding falls 20% and walking time falls 7%, but low-UV exposure rises 40%. An average success is therefore not safe to reuse universally.”

The figures are generated by the shared decision engine and labelled as synthetic MVP output.

## 0:58 — Make Memory change the next decision

Choose **Adapt and save rule**, then **See the worker result** and **Find eligible routes**.

“Cremorne Memory stores the boundary of the result: when UV is at least seven and low UV is required, Route B is filtered before ranking. The next decision starts with the lesson instead of rediscovering the same failure.”

## 1:18 — Prove it is a capacity product

Select **Find a room**.

“The same mechanism works for workspace capacity: only opted-in rooms satisfying size, equipment and accessibility requirements enter the eligible set.”

## 1:28 — Close

“Use the capacity Cremorne already has. Measure every outcome. Make the next decision better.”

## If a judge asks for technical proof

On the CDH screen, expand **Show decision trace**. The status badge confirms whether the deployed serverless API or the identical local deterministic engine produced the run. Open **API JSON** only if the judge wants to inspect the route-level decision contract.
